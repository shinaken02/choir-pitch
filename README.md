# 合唱ピッチ可視化（パート練習サポート）

合唱の各パート（ソプラノ／アルト／テナー／バス）の練習を助けるための Web アプリです。
マイクから歌った声のピッチ（音の高さ）をリアルタイムに検出し、お手本の音程とどれだけ
合っているかを画面で確認できます。サンプルとして **「仰げば尊し」の混声四部** を収録し、
**ソプラノ／アルト／テナー／バス** を切り替えて練習できます。

- マイク音声は **この端末（ブラウザ）の中だけ** で処理され、外部には一切送信されません。
- バックエンド（サーバー）もデータベースもない、フロントエンドだけの静的サイトです。

> 現在の実装範囲は **フェーズ1（MVP）** ＋ サンプル曲のパート別お手本再生・重ね表示までです。

---

## 起動方法（開発サーバー）

事前に [Node.js](https://nodejs.org/)（18以上）が必要です。

```bash
npm install      # 初回のみ。必要なライブラリを取得します
npm run dev      # 開発サーバーを起動
```

表示される `http://localhost:5173/` をブラウザ（Chrome / Edge / Safari）で開いてください。

- マイクを使うには **HTTPS または localhost** が必要です。`localhost` は安全な扱いになるので、
  そのままマイクを許可できます。
- `192.168…` などの数字のアドレスで開くとマイクは使えません。必ず `localhost` で開いてください。

### 公開用ビルド（静的ファイルの書き出し）

```bash
npm run build    # dist/ に静的ファイルを書き出す
npm run preview  # 書き出した結果をローカルで確認
```

## GitHub Pages で公開する

このリポジトリには GitHub Pages 用の自動公開設定（`.github/workflows/deploy.yml`）が入っています。

### 1. GitHub にリポジトリを作って push する

GitHub でリポジトリを新規作成し、このフォルダを push します。

```bash
git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
git branch -M main
git push -u origin main
```

> ⚠️ GitHub の無料プランでは、GitHub Pages は **公開（Public）リポジトリ** が必要です。
> このアプリは個人情報・パスワード・APIキーを一切含まず、マイク音声も外部送信しないため、
> 公開しても情報漏えいの心配はありません（中身はソースコードのみ）。

### 2. GitHub Pages を有効にする

リポジトリの **Settings → Pages → Build and deployment → Source** を
**「GitHub Actions」** に設定します。

これで、以降は `main` に push するたびに自動でビルドされ、
`https://<あなたのユーザー名>.github.io/<リポジトリ名>/` で公開されます。

## 使い方

1. **パート**を選びます（ソプラノ／アルト／テナー／バス）。グラフの高さが選んだパートの音域に合わせて変わります。
2. **「🎤 マイク開始」** を押してマイクを許可します。
3. 声を出すと、画面中央のグラフに音の高さが流れます（縦＝音の高さ／横＝時間）。
   - 画面上部に **音名（例: A4）／周波数(Hz)／基準音とのズレ（セント）** が表示されます。
   - 最寄りの音にぴったりだと **緑**、外れていると **赤** で線が描かれます。
4. **基準音**：チューニング用の単音を鳴らせます。音を選んで「🔔 鳴らす」。
5. **お手本モード**：「お手本（仰げば尊し・〇〇）を再生」を押すと、青いバー（選んだパートの音程）が
   右から流れてきます。点線（＝今の位置）に合わせて歌うと、合っていれば緑・ずれていれば赤で
   自分の声が重なって表示されます。

## 技術構成

| 役割 | 使用技術 |
| --- | --- |
| 土台 | React + TypeScript + Vite |
| ピッチ検出 | Web Audio API ＋ [`pitchy`](https://github.com/ianprime0509/pitchy)（McLeod Pitch Method） |
| 可視化 | Canvas（リアルタイムのスクロール描画） |
| 音の再生 | [`Tone.js`](https://tonejs.github.io/) |

### 主なファイル

```
src/
  audio/pitchEngine.ts     マイク取得＋pitchy によるピッチ検出
  audio/tonePlayer.ts      基準音・お手本メロディの再生（Tone.js）
  music/noteUtils.ts       周波数⇔音名⇔MIDI 変換、セント計算
  music/aogebaSATB.ts      サンプル曲「仰げば尊し」混声四部の音符データ
  components/PitchGraph.tsx Canvas のスクロールグラフ描画
  App.tsx                  画面・操作のまとめ
```

## 歌声特有の課題への対策

- **レイテンシ（遅れ）**：解析バッファを 2048 サンプルと小さめにし、描画は
  `requestAnimationFrame` で軽量に回しています。
- **ノイズ・無声区間**：pitchy の信頼度（clarity）と音量（RMS）が低いフレームは
  ピッチ無しとして線を途切れさせ、誤った点を描かないようにしています。
- **倍音によるオクターブ誤検出**：お手本モードでは、お手本の音に対して 1 オクターブずれた
  検出が起きた場合、近いオクターブへ補正してから比較しています。

## サンプル曲について

「仰げば尊し」（明治期の唱歌）は **メロディの著作権が切れています**（パブリックドメイン）。
本リポジトリには有料の楽譜・MIDI などは含まれていません。

ソプラノは主旋律、**アルト／テナー／バスはパブリックドメインの旋律に基づく簡易な編曲（一例）** です。
お手持ちの楽譜と音が違う場合は、`src/music/aogebaSATB.ts` の `CHORALE` 配列
（`[拍数, ソプラノ, アルト, テナー, バス]` の並び）を書き換えるだけで差し替えられます。
フェーズ2で MIDI 読み込みに対応すれば、本物の楽譜から各パートを自動取り込みできます。
